# Video assets

`music.mp3` is deliberately **not** committed. The track is licensed for use as
one element of an edited audiovisual work, not for standalone redistribution, so
a public repository must not carry the raw file.

To re-render the walkthrough with music, place the cleared track here as
`music.mp3`. The rights record for the track this project used lives with the
author's audio-rights log; without the file the video still renders, with
narration and no music bed.
